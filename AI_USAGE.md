# AI Usage Disclosure

AI tools were used as development assistants during the creation of the **FocusBoard** project.

## Tools Used
* **ChatGPT** – Used for architectural guidance, initial code suggestions, debugging assistance, and documentation support.
* **Claude** – Used for code refinement, component logic structuring, debugging, and UI/CSS troubleshooting.

## Areas of AI Assistance
* Understanding and breaking down assignment requirements.
* Planning the React component hierarchy and structure.
* Generating boilerplate code and initial CSS styling suggestions.
* Understanding React state management and `localStorage` persistence.
* Identifying and resolving runtime or syntax errors during development.
* Refining responsive layouts and UI styling.
* Drafting and formatting project documentation.

## Developer Contribution & Verification
All AI-generated suggestions were critically reviewed, modified, implemented, and tested by the developer. The final application—built with React, JavaScript, HTML, and CSS—reflects the developer's own implementation choices. The developer takes full responsibility for understanding the codebase and verifying the functionality of the submitted project.
